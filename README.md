# Telegram Phone Checker

Локальное приложение для проверки телефонных номеров на наличие зарегистрированных пользователей Telegram через официальный Telegram API ( Telethon + FastAPI ).

---

## 📌 Описание

Приложение принимает текстовый файл с телефонными номерами, разделенными `;` или переносом строки, и выполняет проверку через официальный метод Telegram API:

`contacts.ImportContacts` с использованием `InputPhoneContact`

---

## 🛠️ Требования

- **Python 3.9+**
- Учетная запись Telegram и ключи API (`API_ID`, `API_HASH`), полученные на [my.telegram.org](https://my.telegram.org/).

---

## 🚀 Установка

### 1. Проверка версии Python
Убедитесь, что Python установлен:

```bash
python --version
```

### 2. Создание виртуального окружения
```bash
python -m venv venv
```

### 3. Активация виртуального окружения

- **Windows (PowerShell):**
  ```powershell
  .\venv\Scripts\Activate.ps1
  ```
- **Windows (CMD):**
  ```cmd
  venv\Scripts\activate.bat
  ```
- **macOS / Linux:**
  ```bash
  source venv/bin/activate
  ```

### 4. Установка зависимостей
```bash
pip install -r backend/requirements.txt
```

---

## ⚙️ Настройка Credentials

1. Скопируйте файл `.env.example` или откройте `.env`:
   ```env
   API_ID=YOUR_API_ID
   API_HASH=YOUR_API_HASH
   ```
2. Замените `YOUR_API_ID` на ваш численный API ID.
3. Замените `YOUR_API_HASH` на ваш 32-символьный API Hash.
4. Сохраните файл.

> **ВАЖНО:** Не передавайте и не публикуйте файл `.env` или значения `API_HASH`.

---

## 🖥️ Запуск сервера

Для запуска backend откройте терминал с активированным `venv` и выполните:

```bash
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000 --reload
```

После этого откройте браузер по адресу:

**`http://localhost:8000`**

---

## 🔐 Авторизация в Telegram

При первом запуске приложение попросит авторизоваться в Telegram:
1. Введите номер телефона в формате `+79991234567`.
2. Нажмите **Получить код**.
3. Введите код, полученный в официальном клиенте Telegram.
4. Если включена двухэтапная аутентификация (2FA), введите ваш пароль.

Файл сессии будет сохранен локально в `backend/sessions/tg_checker_session.session`. Повторный ввод кода при следующих запусках не требуется.

---

## 📖 Использование

1. Нажмите **Выбрать файл** и укажите текстовый файл с номерами.
   - Пример формата: `+37369123456;+37368123456;+37360123456`
2. Нажмите **Начать проверку**.
3. Следите за процессом в реальном времени в таблице и строке прогресса:
   - **FOUND** — пользователь Telegram найден.
   - **NOT FOUND** — Telegram обработал номер, пользователь не зарегистрирован.
   - **ERROR** — техническая ошибка при проверке номера.
4. По окончании проверки нажмите **Скачать CSV** для сохранения выгрузки в формате UTF-8 с BOM (для совместимости с Excel).
