Авторизация Telegram

Для работы с Telegram API требуется пройти авторизацию аккаунта.

Вставьте этот ключ в Vercel ➔ Settings ➔ Environment Variables с именем TG_SESSION_STRING чтобы авторизация работала вечно со всех устройств.

Вставьте любой произвольный текст или список контактов. Система автоматически выявит номера, применит нормализацию для Молдовы (069... ➞ +37369..., 68... ➞ +37368...) и выполнит проверку через Telegram.
